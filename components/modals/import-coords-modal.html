📍 Import Member Coordinates from Excel
📋 Excel Format Required
Your Excel file (.xlsx or .csv) must have these columns:
account_no — Member's account number (must match existing records)
latitude — Decimal latitude (e.g. 11.60862500)
longitude — Decimal longitude (e.g. 125.43620000)
⚠️ Column headers must be in the first row. Order doesn't matter.
